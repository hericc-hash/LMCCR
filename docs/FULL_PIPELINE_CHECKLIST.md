### Planner 输入接口

| 字段 | 用途或约定 |
|---|---|
| `global_source` | 全局视觉特征 |
| `raw_E` | 原始任务证据，形状为 `[N,5,3,128]` |
| `coordinate_state` | 模型约定的 47 维坐标状态 |
| `task_quality` | 任务证据质量 |
| `task_valid` | 任务输入有效性掩码 |
| `lordosis_valid` | 前凸判断所需输入的有效性掩码 |

检查点中的三个任务阈值由现有代码分别重复到五个节段，再添加前凸阈值，组成 16 维阈值。补充包中的冻结运行配置已确认前凸阈值为 0.5。有效性掩码不能由诊断标签代替。

### 连接时需要保留的区别

- 辅助 Planner 权重不能单独生成 Direct 草稿，必须恢复该分支的实际输入、提示词和生成过程。
- `generate_scaffold_report.py` 当前输出 raw/修补后的一对报告，不等于已完成 S4 候选池与最终选择。
- 候选文本 embedding 可由模型现场计算，不必将历史 embedding 缓存作为新患者推理必需资产。
- 单组 selector 可以用于连接测试，但不能冒充论文三组集成结果。
- 当前 `predict_clinical16.py` 先要求历史回放通过。新患者推理应有独立入口，同时保留单独的冻结回放验收。
- 当前本地环境为 CPU，尚未验证完整语言模型生成的可行性、耗时与资源需求。
